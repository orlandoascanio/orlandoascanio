## Selected work

I built **PocketLeft** in Swift to track spending from the Mac menu bar. I wanted to see how low my balance could get before payday. The forecast counts rent when it's due and leaves out client invoices until they're paid. [Source](https://github.com/orlandoascanio/pocketleft) · [Forecast test](https://github.com/orlandoascanio/pocketleft/blob/30ddb81577299a05f1056691a768e1fc8616adcb/mac/Tests/PocketCoreTests/ForecastAndHistoryTests.swift#L108) · [Mac release](https://github.com/orlandoascanio/pocketleft/releases/latest)

**ResistGate** is a Chrome extension for sites you open out of habit. Pick a site, and the next time you open it, ResistGate asks you to type a passage for a few minutes of access. Your blocklist stays in the browser. [Source](https://github.com/orlandoascanio/ResistGate) · [Chrome Web Store](https://chromewebstore.google.com/detail/resistgate/elpiihpfmgipodcddhhpiijmppkmlpnc)

**Clean Paste**, my TypeScript plugin for Obsidian, tidies up lists and spacing when you paste text into a note. It leaves code blocks alone. [Source](https://github.com/orlandoascanio/Clean-Paste) · [Cleanup tests](https://github.com/orlandoascanio/Clean-Paste/blob/main/tests/integration/cleaner.test.ts)
